ABOUT THE PROJECT

VoiceTrust AI

An advanced, research-grade multilingual deepfake audio detection system trained on the IndicFakeSpeech dataset comprising 2,300 clips across English, Hindi, and Marathi languages.

The system uses a hybrid CNN + Bi-LSTM architecture with MFCC feature extraction and a language-agnostic Voice Activity Detection (VAD) module to detect synthesised audio generated by TTS engines like gTTS and Microsoft Edge TTS.
